## Notes
- nlohmann/json compiled as header-only (multi-header) — no separate library target needed.
- `load_from_environment()` maps env vars like `AEGIS_CORE_LOGGING_LEVEL` to config key `core.logging.level`, preserving type from schema defaults when possible.
- `validate()` enforces strict mode: all keys in `m_flat` must exist in schema, and all required schema keys must be present.
- Renamed `override()` to `set()` because `override` is a C++11 contextual keyword that MSVC struggles with in some contexts.
- Had to use `build2` because the old `build` directory had locked spdlog git pack files from a prior VS process.
