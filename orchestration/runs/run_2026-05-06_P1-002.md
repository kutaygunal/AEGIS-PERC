## Notes
- MSVC 14.44 (C++20) had trouble with aggregate initialization of an `Entry` struct containing a `std::type_index`. Switching to an explicit constructor fixed the issue.
- Overload resolution between the template `register_service<T>` and the legacy non-template overload caused the legacy test to match the template and use an empty name. Resolved by merging both into a single template that falls back to `service->name()` when no explicit name is provided.
- Circle-dependency detection is implemented lazily at resolution time for factory-registered services.
